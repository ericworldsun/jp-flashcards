📌 懸浮查譯書籤（小說網站用）

在「小説家になろう」「カクヨム」「青空文庫」等網站讀小說時，叫出一顆懸浮球「訳」：
長按選取日文 → 點懸浮球 → 立刻看到中譯；再點一下就能查詳細＋存進單字卡（走「小說生字」牌組，之後自動同步回 Obsidian）。

書籤程式碼（下面一鍵複製）

Android Chrome 安裝步驟（一次就好）

  1. 按上面「複製書籤程式碼」
  2. 隨便開一個網頁 → 網址列右邊「⋮」→「☆ 加入書籤」
  3. ⋮ →「書籤」→ 找到剛存的書籤 → 長按 →「編輯」
  4. 名稱改成「訳」，網址整串刪掉、貼上剛複製的程式碼 → 儲存

之後每次使用

  1. 在小說網頁，點網址列打「訳」，點選出現的書籤（不是搜尋建議）→ 懸浮球出現
  2. 長按選日文 → 點懸浮球「訳」→ 即時中譯
  3. 想存單字 → 點「💾 查詳細／存進單字卡」→ 跳到閱讀器點字儲存（會自動斷詞給讀音）
  4. 再啟動一次書籤＝收掉懸浮球

懸浮球可以拖曳移位。翻譯走 Google 非官方端點，少數網站會擋，擋掉時就用「查詳細」按鈕跳閱讀器查。
