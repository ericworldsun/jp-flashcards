📌 懸浮查譯書籤（小說網站用）

在「小説家になろう」「カクヨム」「青空文庫」等網站讀小說時，叫出一顆懸浮球「訳」：
長按選取日文 → 點懸浮球 → 立刻看到中譯；再點一下就能查詳細＋存進單字卡（走「小說生字」牌組，之後自動同步回 Obsidian）。

書籤程式碼（下面一鍵複製）

Android Chrome 安裝步驟（一次就好）

  1. 按上面「複製書籤程式碼」
  2. 隨便開一個網頁 → 網址列右邊「⋮」→「☆ 加入書籤」
  3. ⋮ →「書籤」→ 找到剛存的書籤 → 長按 →「編輯」
  4. 名稱改成「yaku」（英文才方便在網址列叫出），網址整串刪掉、貼上剛複製的程式碼 → 儲存後點開確認網址開頭還是 javascript:（有些版本會自己砍掉，被砍就重貼一次）

之後每次使用（⚠ 啟動方式是關鍵）

  1. 人先在小說網頁上，點一下網址列 → 打 yaku → 下拉選單裡點旁邊有「★／書籤」圖示的那一項（不是放大鏡的搜尋建議）→ 懸浮球「訳」出現在右下角
  2. 長按選日文 → 點懸浮球 → 即時中譯
  3. 想存單字 → 點「💾 查詳細／存進單字卡」→ 跳到閱讀器點字儲存（自動斷詞給讀音）
  4. 再啟動一次書籤＝收掉懸浮球
🔧 點了沒反應？九成是這三個
  1. 從「書籤列表」直接點開 → 無效。書籤小工具必須「停在小說頁 → 網址列打名字 → 點書籤項」才會在該頁執行。
  2. 點到的是搜尋建議而不是書籤本身（看圖示：要選★書籤那一項）。
  3. 書籤網址開頭的 javascript: 被 Chrome 砍掉了 → 編輯書籤檢查，不在就整段重貼。
不用先裝任何 App 或 PWA，書籤本身就是全部。

懶人替代法：用「分享」送進閱讀器（不用書籤）

先把閱讀器裝成 App（Chrome 開 reader.html → ⋮ →「加到主畫面」→ 安裝）。之後在任何能選字的 App（Chrome 小說頁、部分電子書 App）：

  1. 長按選取日文 →「分享」→ 選「小說閱讀器」
  2. 閱讀器自動開啟：整句中譯＋逐字可查存，完全不用碰書籤

懸浮球可以拖曳移位。翻譯走 Google 非官方端點，少數網站會擋，擋掉時就用「查詳細」按鈕跳閱讀器查。
